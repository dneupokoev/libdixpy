# Changelog

## [0.0.10] - 2026-09-08
### Added
- Настраиваемый таймаут для API-запросов Bitrix24 (параметр `timeout` в `Bitrix24ChatSafeSender`)
- Константы `DEFAULT_TIMEOUT=30` и `UPLOAD_TIMEOUT=60`
### Changed
- Загрузка файлов использует отдельный таймаут (`UPLOAD_TIMEOUT`)

## [0.0.9] - 2026-08-02
### Changed
- Обновлены требования к Python (`>=3.10`) в `setup.py`
- Удалена устаревшая зависимость `typing_extensions`
- Упрощены опциональные зависимости (`extras_require`)
- Актуализированы классификаторы пакетов (добавлен Python 3.13)
- Рефакторинг импортов в `libdixpy/__init__.py`
### Fixed
- Добавлено предупреждение о синхронной работе модуля `bitrix24` в документации и коде

## [0.0.8] - 2026-02-12
### Added
- Новый модуль `bitrix24` с классом `Bitrix24ChatSafeSender`
- Поддержка отправки файлов и изображений в чаты Bitrix24
- Автоматическое определение папки чата через `im.disk.folder.get`
- Зависимость: `requests>=2.31.0`


## [0.0.7] - 2025-09-10
